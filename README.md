# Infinity Installer Manager

Infinity Installer Manager (IIM) is one installer for the whole Infinity.Inc suite.

It ships a command line and a window, like every other product in the suite:/n/n- `inc` - Infinity Cloud
- `ifm` - Infinity File Manager
- `ipm` - InfinityPackageManager
- `iim` - Infinity Installer Manager (this product)

Downloads are published as release assets on this repository.
